# OxMPL

## Agent skills

### Issue tracker

Issues live as markdown files in the developer's personal vault (machine-local, outside this repo): `~/Dropbox/vault/pages/oxmpl/planning/issues/`, one directory per feature. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles with default strings (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix), recorded as `Status:` lines in issue files. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at the repo root, ADRs in `docs/planning/adr/`. See `docs/agents/domain.md`.
