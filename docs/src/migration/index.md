# Migration Guides

OxMPL is pre-1.0: breaking changes ship in minor releases. Each guide below lists what you need to change when upgrading across one minor version. If you are skipping several versions, apply the guides in order.

| Upgrade | Rust | Python | JavaScript |
|---|---|---|---|
| [0.7 → 0.8](0.7-to-0.8.md) | Breaking: rand 0.10 trait rename, Rust 1.85+ | Breaking: Python 3.11+ | No changes |
